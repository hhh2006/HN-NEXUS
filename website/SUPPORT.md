# Support

- Usage questions: open a GitHub Discussion when enabled, or a question issue.
- Bugs: use the Bug Report issue template and include OS, ZSH version, terminal emulator and test output.
- Security concerns: follow [SECURITY.md](SECURITY.md); do not post vulnerabilities publicly.

Community support is best-effort. Include sanitized logs only; never post credentials, tokens, private keys or sensitive host details.
