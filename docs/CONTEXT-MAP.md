# Context map

The current directory name provides a lightweight baseline (Desktop, Downloads, Documents, Projects, Labs, CTF, Reports, Logs, SSH, Docker, Kubernetes). Complete path components can identify named workspaces such as network-recon, packet-analysis, web-security, and exploitation-lab. Current-directory manifests provide stronger project evidence for Python, Node, Docker, Rust, Go, and CMake.

The prompt does not infer a task from the username, does not claim to know what the operator is doing, and does not display Git/environment/SSH badges when those contexts are absent.
