# Contributing

Thanks for helping improve HN NEXUS.

1. Open an issue to discuss substantial changes.
2. Fork the repository and create a focused branch.
3. Keep changes scoped; preserve native command behavior and shell history.
4. Run `bash tests/run-all.sh` and include the complete result.
5. For ZSH changes, include parser/runtime results from a supported ZSH environment.
6. Never include secrets, private logs or personal machine details.
7. Submit a pull request describing the motivation, implementation, testing and any compatibility impact.

Visual changes should include genuine screenshots from the tested environment, with sensitive details redacted.
