# Contributor Covenant Code of Conduct

We are committed to a welcoming, respectful and harassment-free community. Be considerate, assume good intent, accept constructive feedback, and focus criticism on ideas and code rather than people. Harassment, discrimination, threats, doxxing and abusive conduct are not tolerated.

Project maintainers may remove content or restrict participation when necessary to protect the community. Report concerns privately through the repository's verified contact or GitHub reporting tools.
